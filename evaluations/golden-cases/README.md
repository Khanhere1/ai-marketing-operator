# Golden Evaluation Cases

Golden cases define ground-truth benchmarks for offline and simulation evaluation of AI Marketing Operator workflows.

## Case Directory

* `001-high-roas-poor-lead-quality.md` — High platform-reported ROAS paired with low downstream sales lead acceptance.

## Benchmark Execution

Every golden case defines:
1. Input Data Fixtures
2. Expected Diagnosis & Recommendations
3. Critical Failure Modes (Automatic Rejection)
4. Evaluation Scoring Rubric (1-5 Scale)
